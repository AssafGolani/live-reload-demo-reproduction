Scroll-restoration + live-reload gotcha

With withExperimentalPlatformNavigation() the router hands scroll and focus restoration to the browser's native Navigation API instead of Angular's withInMemoryScrolling. When the dev server live-reloads (a full page reload), the browser tries to restore your scroll position before Angular has re-rendered this tall content — so the position it lands on differs from the plain History-API build.

  1. Run npm start and open http://localhost:4200 in Chromium.
  2. Scroll down to one of the bands below and note the Scroll Y readout.
  3. Edit DEMO_MARKER in src/app/app.ts (e.g. 'v1' → 'v2') and save to trigger a live-reload. Watch where the page lands and whether Bootstrapped at changed.
  4. Comment out withExperimentalPlatformNavigation() in src/app/app.config.ts, repeat, and compare the scroll behavior.
